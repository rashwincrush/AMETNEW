# Optional Services and Change Control

## Included in Core SOW (Current Paid Scope)
- Delivery of the Forgecircle Alumni web application features as presently implemented (directory, jobs, events, mentorship, groups, messaging, admin console) per documented scope.
- Supabase-backed auth, database, storage, and direct SPA integration.
- Static frontend hosting (e.g., Vercel) and existing environments already provisioned.

## Not Included / Optional Services (Require Signed Change Order)
- WhatsApp messaging / integrations.
- SMS OTP or any paid SMS delivery.
- Transactional email provider setup (SendGrid/Mailgun/SES/others).
- Premium support SLAs (enhanced response/uptime commitments).
- Production monitoring/alerting (APM, uptime, error tracking) beyond current repo state.
- Additional environments (staging/preview beyond existing).
- New edge functions, APIs, or backend services not in core scope.
- Third-party analytics/tracking tools.
- Any new paid third-party services or licenses.

## Change Control Procedure
- **Intake:** Client submits written change request (email or ticket) describing scope, acceptance criteria, and timing.
- **Assessment & Estimate:** Vendor provides written impact on effort, timeline, and cost.
- **Approval:** No work starts until Client provides written approval of the estimate and both parties sign a Change Order or SOW Addendum.
- **Execution:** Approved changes are scheduled; timelines and fees adjust per the signed change document.
- **Tracking:** Changes tracked separately from core scope; progress/status reported alongside the main project plan.

## Acceptance Criteria & Completion Certificate
- Core scope acceptance is based on the already-signed SOW deliverables and the Acceptance Criteria therein.
- Optional/extra services are only delivered after a signed Change Order/SOW Addendum; completion and acceptance for those items are documented in that change document.
- Issuance of a Completion Certificate (or equivalent acceptance sign-off) confirms that in-scope deliverables meet the agreed Acceptance Criteria; it does not imply acceptance of any future or unapproved changes.
